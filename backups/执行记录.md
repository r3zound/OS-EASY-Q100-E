1. 把 CSME System Tools v16.0 r8 拷到 Windows 上
2. 管理员 CMD
3. cd 到 Flash Programming Tool\WIN64
4. fptw64.exe -i            # 看芯片信息
5. fptw64.exe -d H610_full_32mb_V1.bin  # 备份
6. certutil -hashfile full_32mb.bin SHA256
7. fptw64.exe -d H610_full_32mb_V2.bin  # 第二次备份
8. certutil -hashfile full_32mb.bin SHA256   对比两次备份的SHA256值
