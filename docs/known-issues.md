# 已知问题

## 1. 接口 / 硬件设计层面

### 1.1 M.2 2280 接口失效
- 现象：插上 M.2 NVMe SSD 后 BIOS 认不到盘
- 根因：M.2 直连 CPU 的 PCIe 通道，12 代 ES CPU 在该主板上有兼容性问题
- 用户自述：自己机器 M.2 接口失效
- 临时方案：用 **WIFI 转 M.2 转接板** 走 M.2 2230 E Key 槽（仅 PCIe 3.0 x1）
- 14 代适配相关：i5-14400 的 PCIe 通道布局与 12 代基本相同，理论上同样有该问题

### 1.2 miniPCIE 接口实际是 mSATA
- 现象：板上丝印 `mPCIE_1`，但实际是 mSATA
- 根因：政企定制板命名混乱 / BOM 复用
- 临时方案：mSATA SSD 直插，或在 BIOS 中启用 mSATA 隐藏选项

### 1.3 M.2 2230 E Key 槽
- 用途：装 WiFi 6 + 蓝牙模块
- 坑：部分批次壳体没留天线孔，需自己打孔或外置天线

## 2. 14 代适配相关问题

### 2.1 microcode 不全
- 原 BIOS 极可能只含 ADL-S (12代) microcode
- 12代 → 14代 必须追加 RPL-R microcode

### 2.2 ME 兼容性（潜在）
- 原 ME 12.x 可能与 14 代 RPL-R 不完全兼容
- 表现：即使注入 microcode 也可能卡在 MRC 阶段
- 应对：先尝试只改 microcode，不行再考虑升级 ME

### 2.3 Intel Reference Code（潜在）
- 原 RC 可能只支持 ADL-S / RPL-S
- 应对：如果只改 microcode 不亮，备选方案是移植其他 H610 板的 RC

### 2.4 13/14 代 Vmin 不稳定
- 13/14 代 K/KF 桌面 U 有 Vmin 崩溃问题
- **i5-14400 是非 K，受影响小**，但建议用 Intel 最新微码（含 0x12x 系列修复）

## 3. 散热类（与 CPU 升级相关）

- 1.5L 薄型机箱，下压式风扇 + 短铜管
- 长时间满载散热上限约 45-65W
- **i5-14400 TDP 65W** 长时间满载会撞墙，但短时任务影响不大
- 比 i9-12900K (220W) 友好得多
- 比 i3-12100 (60W) 略高，但核显 UHD 730 → UHD 730 同档，发热略增

## 4. 电源类

- 原装电源 90W DC 圆口
- i5-14400 PBP 65W、MTP 148W（实际一般跑不到）
- 90W 电源对 i5-14400 足够（不像 i9 那么紧迫）

## 5. 刷写工具类

- **CH341A + 烧录夹** 是主流方案
- 强烈推荐用 **NeoProgrammer**（不要用 CH341A编程器.exe，后者读出来不完整）
- 夹芯片时红线对 1 脚，夹不紧会接触不良
- **改 BIOS 前必须用编程器备份**原厂（系统内刷没试过、出问题后果自负）
