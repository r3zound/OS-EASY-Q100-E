# 噢易乾 Q100-E 硬件参数

## 1. 官方规格

来源：[噢易云官网 - X86 云终端乾 Q100-E](https://www.os-easy.com/a/359.html)

| 项目 | 参数 |
| --- | --- |
| 型号 | 乾 Q100-E / Q100-E10 / Q100-E60（批次不同型号略异） |
| CPU | Intel 12 代 / 13 代酷睿处理器 I5/I7 可选（标压，TDP 65W） |
| 内存 | 2 × DDR4 SODIMM（笔记本内存），标配 8GB，最大 64GB |
| 存储 | 1 × M.2 2280（NVMe，标配 512GB）+ 1 × mSATA（可扩展，最大 2TB） |
| 网络 | 1 × 1000M（可选 2 × 1000M，定制） |
| 显示 | 1 × HDMI + 1 × VGA |
| USB | 8 × USB（前置 4 × USB3.2 Gen1 + 后置 4 × USB2.0） |
| 音频 | 2 × MIC-IN + 2 × AUDIO-OUT |
| 串口 | 1 × RS-232（COM 口） |
| 其他 | 1 × DC 电源口、1 × 防盗锁孔、1 × IR 红外 |
| 管理 | 支持上电自启、支持冷/热唤醒（适合云终端） |
| 体积 | 200 × 200 × 44.4 mm，1.5L（薄型金属壳，3000 散热微孔 + 侧面橙色散热条） |
| 电源 | DC 圆口，~90W（按 CPU 功耗选） |

## 5. 散热结构

- 1.5L 薄型机箱，下压式风扇 + 单铜管
- i3-12100 (60W) → 满载温度可控
- i5-14400 (65W) → 长时间满载温度比 12100 略高
- 相比 i9-12900K (220W) 友好得多
- 短期任务（编译、渲染）温度可控

## 6. 关键非官方信息（来自第三方评测）

来源汇总见 [references.md](references.md)。要点：

- **LGA1700 插座** — 与桌面 12/13/14 代通用
- **DDR4 SODIMM 笔记本内存** — 不要买成台式机 DIMM
- **M.2 2230 E Key 槽** — 走 WiFi 通道，需自配天线
- **板上丝印 mPCIE_1 的口实际是 mSATA**
- **政企定制 BIOS** — 锁了部分电源管理项
- **原厂无加密芯片** — 编程器刷写不被锁
- **ME 区域可能独立** — 32MB 整片 flash 包含 ME
